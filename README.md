# MedEco Pharmacy Dashboard
A fully responsive, web-based, dashboard with interacvtive data visualization targeted to pharmacies as part of the MedEco system,
where the pharmacy manager can check out the dashboard and easily get an overview of the medicine and points exchange throughout the system.

## Technologies Used:
HTML
CSS
Bootstrap
JavaScript
Chart.js
